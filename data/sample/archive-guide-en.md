# Demo Archive Guide (sample document)

This is a fictional sample document written only to try out the application. It is not real product documentation.

## Signing in
Open the archive website in your browser, type your user name and password on the sign-in page and click "Sign in". If you forgot your password, use the "Reset password" link below the form.

## Creating a user profile
An administrator opens the "User management" menu, chooses "New user", fills in first name, last name and role, and saves. A profile can belong to one or more user groups, and the groups decide which collections the user can see.

## Searching documents
Use the search box at the top of every page. Type a title, an author or a few words from the text. Results can be filtered by document type and by date. Click a result to open its details page.

## Adding a document
Choose "Add document", upload a PDF or an image, fill in the title and the document type, and press "Save". Large scans may take a few minutes to be indexed.

## Getting help
The help menu contains the user guide. Administrators can also send questions to the support team from the "Contact support" page.
